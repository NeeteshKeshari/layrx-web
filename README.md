# LayrX Marketing Website

Modern, interactive landing page for LayrX — repository intelligence and grounded AI.

## Sections

- **Hero** — value proposition and live pipeline preview
- **Why LayrX?** — differentiation from generic AI coding tools
- **Architecture** — interactive layer explorer (CLI → Gateway → Packages)
- **Features** — phase-by-phase capability breakdown
- **Demo** — interactive previews (Repository, AI, CLI)
- **Installation** — step-by-step setup with copy-to-clipboard
- **Documentation** — links to phase guides
- **GitHub** — open-source CTA

## Run locally

```bash
cd web
npm install --no-workspaces
npm run dev
```

Open **http://localhost:5174**

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- No backend — static site
